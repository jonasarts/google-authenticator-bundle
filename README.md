google-authenticator-bundle
===========================

A Google Authenticator (TOTP/HOTP) bundle for the Symfony framework.

[![Latest Stable Version](https://poser.pugx.org/jonasarts/google-authenticator-bundle/v)](https://packagist.org/packages/jonasarts/google-authenticator-bundle)
[![Total Downloads](https://poser.pugx.org/jonasarts/google-authenticator-bundle/downloads)](https://packagist.org/packages/jonasarts/google-authenticator-bundle)
[![License](https://poser.pugx.org/jonasarts/google-authenticator-bundle/license)](https://packagist.org/packages/jonasarts/google-authenticator-bundle)
[![CI](https://github.com/jonasarts/google-authenticator-bundle/actions/workflows/ci.yml/badge.svg)](https://github.com/jonasarts/google-authenticator-bundle/actions/workflows/ci.yml)

Requires PHP 8.4 and Symfony `^7.0 || ^8.0`.

This bundle is based on the ideas of [Christian Stocker](https://github.com/chregu)
and [Michael Kliewe](https://github.com/PHPGangsta).
